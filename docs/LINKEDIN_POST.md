# LinkedIn Showcase Post

🚀 **Building a Production-Grade Android App with Kotlin & Jetpack Compose!**

Small projects often teach the biggest lessons. Over the past few days, I set out to transform a simple tip calculator into a published-grade portfolio application called **Neon Tip Calculator** ⚡.

Here is what I built under the hood:
- 🎨 **Modern Declarative UI**: Jetpack Compose & Material3 with custom glowing radial canvas shaders and responsive two-pane tablet layouts.
- 💰 **Precise Financial Math**: Replaced floating-point numbers with `BigDecimal` and strict input sanitization to eliminate rounding errors.
- 🛠️ **Clean Architecture**: Followed strict MVVM + Unidirectional Data Flow (UDF) using Kotlin Coroutines and StateFlow.
- 💾 **Local Persistence**: Integrated **Room Database** for calculation history with swipe-to-delete and **Preferences DataStore** for persistent user settings.
- ⚡ **Dependency Injection**: Powered by **Dagger Hilt** for clean modular code.
- 🌐 **Localization & Accessibility**: Full English & Bangla (`values-bn`) support with TalkBack semantic tags.

💡 **Key Takeaway**: Paying attention to edge cases (like multi-currency symbols, decimal validation, and screen rotation survival) is what turns a basic project into a polished, professional app.
